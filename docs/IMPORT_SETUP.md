# 입출금 알림 자동 가져오기 설정

은행·카드 앱의 알림이나 문자를 가계부로 보내면 **확인 대기함**에 쌓입니다. 바로 등록되지 않으니 안심하고 켜두세요.

## 0. 기기 토큰 발급 (공통)

1. 가계부 앱에서 **설정 → 자동 가져오기 → 이 기기 토큰 만들기**를 누릅니다.
2. 표시된 **웹훅 주소**(`https://<배포 주소>/api/import`)와 **토큰**을 복사합니다. 토큰은 이때 한 번만 보입니다.
3. 토큰이 유출되면 같은 화면에서 폐기하고 새로 만드세요.

> 토큰은 본인 계정에 묶입니다. 남편 폰과 아내 폰은 각자 자기 토큰을 씁니다.

## 1. 안드로이드: 알림 전달 앱

문자뿐 아니라 은행·카드 **앱 푸시 알림**도 보낼 수 있습니다.

1. Play 스토어에서 알림을 웹훅으로 전달하는 앱을 설치합니다. 'SMS/알림 포워더'로 검색하면 됩니다.
   ('알림 접근 권한'과 'HTTP/Webhook 전송'을 지원하는 앱이면 무엇이든 됩니다.)
2. 앱에 **알림 접근 권한**을 줍니다.
3. 전달 규칙을 만듭니다.
   - 조건: 본문에 `입금` 또는 `출금` 또는 `승인` 또는 `결제` 포함
   - 동작: Webhook (POST, JSON)
   - URL: 0단계의 웹훅 주소
   - 헤더: `Authorization: Bearer <토큰>`
   - 본문:
     ```json
     { "text": "%알림 제목% %알림 본문%", "source": "notification" }
     ```
     `%...%` 자리에는 각 앱에서 제공하는 변수를 넣습니다.
4. 배터리 최적화에서 이 앱을 **제외**해야 백그라운드에서도 동작합니다.

## 2. 아이폰: 단축어 자동화

iOS는 다른 앱의 푸시 알림을 읽을 수 없으므로 **문자 알림**을 쓰는 은행·카드만 가져올 수 있습니다. 카드사 앱 설정에서 승인 알림을 '문자'로 바꿔 두세요.

1. **단축어** 앱 → **자동화** → **+** → **메시지**를 선택합니다.
2. '메시지 내용 포함'에 `원`을 입력하고 **즉시 실행**을 선택합니다. 실행 전 확인 끄기는 iOS 17 이상에서 가능합니다.
3. 동작을 추가합니다.
   1. **URL 콘텐츠 가져오기**
      - URL: 웹훅 주소
      - 방법: `POST`
      - 헤더: `Authorization` = `Bearer <토큰>`
      - 본문 요청: JSON, `text` = *단축어 입력*(메시지 내용), `source` = `sms`
4. 키워드 필터는 서버가 다시 하므로, 단축어에서는 `원`만 걸러도 충분합니다.

## 3. 동작 확인

설정 화면의 **테스트 보내기** 버튼이나 아래 명령으로 확인할 수 있습니다.

```sh
curl -X POST https://<배포 주소>/api/import \
  -H "Authorization: Bearer <토큰>" -H "Content-Type: application/json" \
  -d '{"text":"KB국민 출금 12,300원 스타벅스","source":"manual"}'
```

확인 대기함에 1건이 생기면 성공입니다.

## 개인정보

- 키워드(`입금`·`출금`·`승인`·`결제`)가 없는 알림은 서버에서 저장하지 않고 버립니다.
- 원문은 확인 대기함에서 본인만 볼 수 있습니다. 등록하거나 무시한 뒤에는 원문을 지울 수 있습니다.
